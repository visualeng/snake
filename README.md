# 🐍 Змейка на Python

Классическая змейка на встроенном модуле `turtle`. Ничего доустанавливать не надо.

## Запуск

```bash
python snake.py
```

## Управление

| Клавиша | Действие |
|---|---|
| ← ↑ → ↓ | движение |
| Esc | выход |

## Возможности

- Растёт с каждым съеденным яблоком 🍎
- Постепенно ускоряется
- Считает очки и рекорд
- Проигрыш при ударе о стену или в себя

## Как это работает

- `turtle` — графика, встроен в Python
- Змейка — список «квадратиков», каждый кадр тело едет по цепочке за головой
- `screen.tracer(0)` — отключает автоперерисовку, иначе тормозит
