# 🐍 Змейка на Python

Классическая змейка на встроенном модуле `turtle`. Ничего доустанавливать не надо.

## Запуск

```bash
python snake.py
```

## Управление

| Клавиша | Действие |
|---|---|
| **W A S D** | движение (работает и в русской раскладке: цфыв) |
| ← ↑ → ↓ | тоже работает |
| Esc | выход |

## Возможности

- Растёт с каждым съеденным яблоком 🍎
- Постепенно ускоряется
- Считает очки
- **Рекорд сохраняется между сессиями** (файл `best.txt`)
- Проигрыш при ударе о стену или в себя

## Как это работает

- `turtle` — графика, встроен в Python
- Змейка — список «квадратиков», каждый кадр тело едет по цепочке за головой
- `screen.tracer(0)` — отключает автоперерисовку, иначе тормозит

## Что можно докрутить

- [ ] Режим «прохождение сквозь стены»
- [ ] Разные фрукты с разными очками
- [x] Сохранение рекорда между сессиями
